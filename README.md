# Is My Color Your Color?

A color-perception test inspired by [ismy.blue](https://ismy.blue/), but covering all six adjacent pairs on the color wheel: red↔orange, orange↔yellow, yellow↔green, green↔blue, blue↔purple, and purple↔red.

Live site: https://skynab.github.io/IsMyColorYourColor/

## Files

- `index.html` — markup
- `ismycolor.css` — styles
